# 启动脚本

普通使用打开 **01_平台/一键启动.bat**。入口会展示硬件、选择 CPU/GPU、准备根 Python 环境与 npm 依赖，然后启动网页、API 和 Worker。网页默认 http://127.0.0.1:3000/ 。保持窗口开启，Ctrl+C 停止它启动的服务。

| 分类 | 文件 | 用途 |
| --- | --- | --- |
| 01_平台 | 一键启动.bat | 准备环境并运行完整平台 |
| 01_平台 | 仅配置环境.bat | 选择 CPU/GPU 并安装依赖，完成后不启动服务 |
| 02_命令行 | 启动CLI.bat | 网址 TXT + 一句需求，结果写入 output/cli |
| 02_命令行 | 启动建议助手.bat | 独立终端对话，真实模型使用根 .env 配置 |
| 02_命令行 | 建议助手离线演示.bat | 固定演示回复，不调用付费模型 |
| 03_开发维护 | 启动API.bat / 启动Worker.bat | 分别运行后端进程；处理网页任务需要两者同时运行 |
| 03_开发维护 | 仅启动前端.bat | 单独预览网页；设计预览可独立使用，实际研究还需后端 |
| 03_开发维护 | 运行全部检查.bat | 手动运行既有测试与依赖检查 |
| 03_开发维护 | 仅检查建议助手.bat | 手动运行助手隔离测试 |

所有 BAT 先根据自身位置回到项目根目录；请保留整个项目目录结构。旧根目录 CMD 与助手子目录重复按钮已归并，不再从旧位置启动。桌面单独交付给设计组的前端包不在此次整理范围内。

```text
BAT → 快速部署/Start.ps1 → 环境准备 → app.local_service → API + Worker + Next
BAT → scripts/Launch.ps1 → 本机部署配置选择的 Python → CLI / 助手 / 单服务 / 检查
```

单独运行工具前请先配置环境。Launch.ps1 复用快速部署/config.local.json 中明确选择的 Conda/Python；默认使用根 .venv。PowerShell 的 scripts/Start-Api.ps1、Start-Worker.ps1 仍保留为固定根环境的底层入口。命令行工具不额外创建环境。

结果结构见 [output/README.md](../output/README.md)，环境配置见 [快速部署](../快速部署/README.md)。端口已占用时，请先在旧服务窗口按 Ctrl+C；不要重复启动同一个服务。
