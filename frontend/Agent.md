# Agent · 主项目前端协作入口

先读../AGENTS.md与README.md。本目录当前包含实际研究入口和独立设计预览；桌面交接包是独立的纯前端快照，不能将主项目服务端代码直接覆盖过去。

人类负责视觉和交互设计确认；AI负责环境、运行、排错及按确认方案实现。不增加登录或用户中心。

主项目运行：启动脚本/01_平台/一键启动.bat准备根.venv与npm依赖，启动API/Worker/Next。单独改前端可在此处npm ci、npm run dev，Node.js需要24+。按终端实际地址访问，端口占用不结束其他程序。设计预览不需要后端。

ResearchWorkspace是模式聚合层；LiveResearch是实际任务聚合层；ResearchPrototype是演示聚合层。实际数据经同源Node转发，服务token只在服务器环境。不要用NEXT_PUBLIC暴露密钥、不要在浏览器直接调用付费LLM、不在功能组件中绕过聚合层访问其他组件。

数据不足直接导出。GAN生成前先由用户选择，固定按真实训练集×5；生成后t-SNE与数值检查、再次确认采用。质量失败不得采用，确认后不得重新生成不同批次。验证与测试保持真实独立；真实验证未改善时回退并说明。真实训练参数保持JSON默认5000轮，不为演示修改正式配置。

实际页面只显示服务返回的图和指标；缺失产物不得用演示替代。设计预览固定fixture始终标记演示。刷新可通过任务编号恢复；切换模式保留当前任务，浏览器关闭不取消Worker。

所有者2026-10-22已恢复本轮测试，npm test的10项交互测试及typecheck通过；本轮未做build或浏览器视觉验收，详情见../docs/验证记录_20261022.md。分享设计交接包只带独立源码、依赖锁、说明与预览图，不带Node服务代理、Python、.env或缓存。
