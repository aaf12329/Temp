# Agent · 前端运行与设计交接

给接手的AI：先读README.md。此目录是独立前端，不需要父目录项目。

人类负责布局、颜色、字体、视觉风格、交互方案与最终设计确认；AI负责环境检查、启动、报错处理、指出源码位置和按人类确认的方案实现。不要擅自改变业务流程。

## 启动

1. 在本目录检查node --version、npm --version，需要Node.js 24+。缺失时说明原因及官方安装入口 https://nodejs.org/ ，按所在环境授权处理系统安装。
2. 执行npm ci，保留package-lock.json，不用--force绕过冲突。
3. 执行npm run dev，打开实际打印的Local地址，通常http://127.0.0.1:3000；端口占用时不要结束其他程序。
4. 验证“产业信息研究平台”“独立演示，未接后端”确实出现。告诉人类地址、顶部编号切换方式，以及Ctrl+C停止方式。
5. Windows独立交接包也可双击“启动预览.bat”；首次安装依赖，以后复用本目录node_modules。

## 查看流程

顶部默认展开九个直接预览按钮，1输入、2处理、3结果、4建模选择、5GAN生成、6t-SNE确认、7XGBoost、8模型评估、9分析建议。当前只有一个URL，不是九条页面路由。

直接跳转会重置选择并使用预设演示状态。要检查选择传递：从4开始，选框架和生成倍数，逐阶段推进到6，选择采用或不采用，再到7、8、9。质量检查失败会禁用采用按钮；XGBoost页面能演示失败和重试。

数据不足分支直接进入整理CSV与文字报告，不显示模型指标。要验证完整输入，在首页选演示分支，再下载/读取示例TXT并输入需求，手动推进。

## 文件与边界

- ResearchPrototype.tsx：显式聚合入口；src/lib/research-flow.ts：状态类；页面在src/features/research。
- src/app/globals.css：基础结构样式。src/components/AnalysisChart.tsx：共用SVG图。
- demo.ts与src/lib/demo-analysis.ts：合成fixture，必须保留演示标记。
- 5倍是可改的前端演示选项，未修改真实训练配置。t-SNE为固定布局；回测/SHAP是独立占位；性能数字来自固定合成行，不是真实训练。
- 不创建Python环境，不配置数据库、CUDA或密钥，不向网址发请求。不接后端、不新增登录、不调用训练或LLM，除非人类后续明确授权。
- 无浏览器持久存储，刷新后状态清空。下载仅保存浏览器文件，不写项目output。

## 验证与交付

执行npm test（8项）、npm run typecheck、npm run build；浏览器分别验证数据不足、跳过GAN、采用/拒绝GAN、检查失败、训练失败恢复、报告下载，以及宽/窄屏布局。报告实际看到的状态，不把启动命令运行过当成成功。

分享只带源码、配置、依赖锁和说明，不带node_modules、.next、.env、个人数据、Python或后台服务。完整目录可独立复制，路径相对本目录；不要从设计交接包自动推送或发布。
