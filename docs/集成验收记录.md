- 研究任务只读本项目成功材料，校验正文哈希与路径，输出候选事实 CSV/JSON 和趋势缺口状态。
- 建议任务使用后端选定证据及已完成研究摘要；操作缓存阻止重复模型调用。未知付费结果明确失败，不自动再调用。

- 根配置、安装脚本和启动按钮统一；组件依赖锁文件改为相对引用根锁文件，清除了原本指向旧电脑 wheel 的绝对路径。
- 增加 Celery 任务入口、数据库补投扫描、Linux Docker/Compose 配置；消息只含 ID，复用已有任务执行器。

## 实际进程与模型计算

scripts/smoke_service.py 已启动真实 Uvicorn 进程，并通过 HTTP 提交演示建议；独立 Worker 进程从临时数据库领取任务，查询返回 done，会话为一轮，匿名请求被拒绝。API 与 Worker 验收后均已退出。

scripts/verify_environment.py 使用本地固定版本模型计算两条合成文本，输出形状 [2,512]，向量有限且归一化，使用 CPUExecutionProvider；XGBoost 完成合成数值的 CPU 拟合。上述计算不等于真实产业预测或建议质量评测。

模型：Xenova/bge-small-zh-v1.5，revision 为 75c43b069aac4d136ba6bc1122f995fedcfd2781。ONNX 文件 24,010,842 字节，tokenizer 439,125 字节；清单带各文件 SHA256。缓存位于 data/models/bge-small-zh-v1.5-int8，不入库。

## 路径与环境约定

配置默认 data、sqlite:///data/platform.db，材料引用 data/normalized/...，脚本从自身位置定位根目录。只有运行时文件操作、数据库连接和边界检查才解析绝对路径；HTTP 返回与研究导出不写开发机目录。

已修正 Windows 深层临时路径超长，以及 PowerShell 5.1/批处理中文路径编码问题。移动项目后重建 .venv；虚拟环境和可编辑安装自身可能带绝对路径，因此不能把整套环境直接搬走当作可移植运行时。

环境扩展阶段系统盘剩余空间观测约 122.66 GB → 122.20 GB；此为系统盘观测差值，不能精确归因到单一任务。未进行跨盘移动，也未删除原始独立项目或其环境。本轮使用 0 个子代理。

## 仍需后续验证或实现

1. 本机没有 Docker，WSL 尚未安装；尚未构建容器或实际运行 Redis/PostgreSQL。Windows 当前使用已有持久数据库队列，目标容器入口已提供。
2. 根 .env 的 INDUSTRY_ADVISOR_API_KEY 当前需用户自行配置真实密钥；本轮没有从历史聊天复制密钥，也未发起真实模型调用。
3. 自动化采集验证使用假 HTTP，尚未进行本轮真实站点小样本验收；正式使用前人工声明站点策略。
4. 浏览器与 TLS 档依赖已安装，但服务出站闸门未适配，当前明确拒绝对应开关。浏览器二进制未安装。扫描 PDF 无 OCR；现有 PDF 页码是组件基于文本流的近似定位，不能等同通用版式解析。
5. 当前为单可信 Bearer 调用方；project_id 校验材料归属，不能充当用户身份和项目授权。多用户登录、Next.js/React、审核管理与训练 HTTP 入口未开发。
6. 机器候选默认 pending；没有审核后的可比时间序列，不能产生可信产业趋势结论。语义阈值尚未经独立人工标注集校准。
7. 文件锁限速与 JSON 状态要求共享同一文件系统，多主机部署前需统一限速与共享文件策略。
8. 表格 HTML 沿用组件解析后的输出，未实现原始字节区间保真。正式全链路合同尚缺的字段定义仍见接口边界文档。
