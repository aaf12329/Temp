# 接口缺项与实现边界

2026-10-21 更新：真实组件现已通过独立适配层接入。正式合同缺项仍保留；当前服务实现以根 README.md、集成说明和验收记录为准。

依据：用户提供的 v1.2 爬虫合同及项目目标文档，原文保存在 `source/`，未修改。

## 尚缺的正式定义

1. 合同引用的《产业分析平台_全链路API.md》未提供。本次不自行定义 ResearchParams、SearchHit、Fact、Answer 等跨层模型。
2. Profile、robots、signals、tool_fallback、storage、Tool 等沿用 v1.1，但完整结构未给出。已知字段显式建模，其余结构保持可扩展，避免虚构封闭标准。
3. v1.2 列出十种 Verdict，但未列出所称四种 Status 的具体值。Status 保持字符串，counts 的临时聚合规则已写在接入说明中。
4. 二十个错误码只展开 E_PDF_PARSE 和 E_PDF_NO_TEXT，其余十八个未提供。框架新增的 E_UNAUTHORIZED、E_IDEMPOTENCY_CONFLICT、E_CRAWLER_NOT_CONFIGURED 等为服务内部错误码，未冒充正式爬虫错误码全集。
5. Plan 和 Material 完整封装未展开，HTTP 映射也没有 plan 路由；当前没有伪造这些能力。
6. 正文的 storage 子字段没有展开。当前材料读取暂接受 storage.text_path，PDF 支持 pdf.text_path。
7. 幂等键的作用域、有效期与冲突行为未给出。本地版本采用单调用方、永久键、相同任务或幂等键必须对应同一完整请求，否则返回 409。
8. `job_id` 由请求者提供，记录 ID 依据原始 URL 字符串计算，暂不执行自动 URL 归一化或跨任务合并。

## 已作出的服务实现选择

- 保留原合同全部九个 HTTP 映射，另增 POST retry；原 GET retry 因会修改状态而标记弃用，保留兼容并禁止缓存。
- HTTP 异步任务是持久任务，非 FastAPI 进程中的 BackgroundTasks；数据库待执行项与任务在同一事务创建。
- 开发机先使用 SQLite 和独立数据库队列 Worker。PostgreSQL 驱动与迁移已准备，真实连接和并发运行尚待环境提供后验证。
- 站点策略必须人工声明；初始化不覆盖现有条目。没有策略不默认允许，登录和路径检查执行于 Worker，适配器仍需完整实施网络访问限制。
- 已设置单调用方 Bearer 密钥；多用户身份、项目级授权、租户隔离和前端登录尚未实现。requested_by 是业务元数据，当前不作为可信登录身份。
- 临时内部 outcome 与合同 counts 对应，和原合同未列全的 status 分开。部分成功并有失败才为 partial；只有失败和跳过则为 failed；全部跳过为 done 且 skipped 计数可见。
- 自动重试最多两次；用户显式重试开始新的尝试周期。失去租约的执行者不能提交数据库结果；外部采集和文件副作用仍需适配器保证幂等。
- 数据库是任务和材料记录的持久来源，pages.json 是提交后生成的兼容快照，允许通过 export 命令重建。

## 真实爬虫接入前需要解决的合同冲突

合同要求“文件名只由 URL 哈希决定”以及“原始字节不许改动”。同一 URL 在不同时间返回不同内容时，两者需要进一步的版本化规则才能同时成立。当前只建立目录与读取边界，没有自行覆盖或编造原始材料。建议在正式合同中明确采集批次/内容版本的目录与引用方式，再实现落盘。

“HTML 表格片段字节保真”需要真实解析实现说明如何定位原始字节区间；DOM 序列化不能自动视为字节保真。PDF 表格的 html_path 如何表达原始依据也待明确。

## 当前不包含的业务能力

现已接静态 HTML/文本 PDF、robots/跨进程限速、正文与表格规范化、待审核事实 CSV、CPU 语义召回和证据建议任务。OCR、浏览器/TLS 服务出口、完整实体归并与产业口径计算、多用户授权、审核管理接口和训练服务入口仍待后续。真实模型需根配置密钥；本轮自动化验收使用假网络与假模型，不能代替实际产业数据质量验收。
