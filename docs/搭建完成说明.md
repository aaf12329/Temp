## 已搭建内容

- Python 3.12.14 虚拟环境位于项目根目录 `.venv`，所需依赖已安装到该环境。
- `pyproject.toml` 声明依赖，`requirements.lock.txt` 锁定本机已验证版本。
- FastAPI 接口、Bearer 鉴权、统一错误体和爬虫 API v1.2 版本标识。
- 爬虫画像、异步任务提交、进度、幂等、失败重试、站点策略和材料读取接口。
- 独立 Python Worker，采用数据库持久任务队列，包含租约、心跳和中断恢复。
- SQLAlchemy 数据模型与 Alembic 迁移。本机已初始化 SQLite，PostgreSQL 驱动和迁移配置已准备。
- 数据目录及人工站点策略文件；段落、正文和结构化表格的读取入口。
- 爬虫适配器协议，便于后续接入现有 Python 采集程序。
- 启动脚本、接入说明、接口缺项记录和 OpenAPI 描述。

当前没有创建 React/Next.js 应用，网页样式留待用户设计。项目也未实现真实抓取算法、产业推断或多用户系统。

## 本地运行方式

1. 在项目根目录双击 `启动API.cmd`。
2. 浏览器打开 `http://127.0.0.1:8000/docs` 查看接口。
3. 接入爬虫并配置站点策略后，在另一个终端运行 `启动Worker.cmd`。

根目录 `.env` 已生成随机 API 密钥。密钥仅保留在本地配置中，未写入本文或接口描述。

当前未配置真实爬虫，API 可以启动；就绪检查会明确返回 `waiting_for_crawler`，任务提交会返回 `E_CRAWLER_NOT_CONFIGURED`，避免生成虚假结果。验证使用的测试服务器已停止，当前没有留驻服务进程。
