# 本项目入口

这是可独立安装的“产业研究建议助手”包，现已通过平台适配层接线，仍保留终端运行。

先读平台根 `../AGENTS.md`、`../README.md`，再读本目录说明。统一环境为平台根 `.venv`，不在本目录新建环境；源码包为 `advisor_bot`。

规范唯一入口：`<本地规范目录>/01_AI项目协作参考\README.md`。按索引选择工程、Python 与 LLM/Agent 规范，不在本项目复制规范正文。

本次用户明确要求：聊天、记忆与摘要使用 JSON 键值对，优先于参考规范中人工库逐行文本的默认约定。

`.env` 是本地真实密钥配置，禁止打印内容或写入源码、报告、测试样例和发布包。自动化测试使用假模型；真实 API 验收需依照用户的实际授权范围。

本包只给建议；主平台适配器提供后台任务与证据上下文，不在本包中引入 FastAPI、数据库或爬虫依赖。调用与配置边界见平台根说明，GUI 暂不开发。
