# 模块合同与验收

状态：独立舱段已实现，尚未总装。日期：2026年10月20日。

## 外部合同

- 入口：`build_bot(BotSettings(...))`，不联网、不创建运行数据。
- 建议：`Advisor.ask(question: str, session_id: str = "default") -> AdviceResponse`。
- 摘要：`Advisor.compact(session_id) -> {through_turn, summary}`。
- 人工记忆：`memory.entries()` 返回 id/text 列表；`memory.change(add/update/delete, text, id)` 返回 id/text/deleted。
- 失败：抛出 `BotError`，可取 code/message/retryable 或调用 as_dict；终端转换为固定错误体。

建议响应字段固定为 session_id、turn、mode、reply；reply 归一化为 content、reasoning、usage、tool_calls。原始 assistant 保存在流水中，公共序列化不包含内部 raw_assistant。
