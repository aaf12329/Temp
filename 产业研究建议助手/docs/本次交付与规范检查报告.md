## 独立助手的位置与运行

项目目录：`产业研究建议助手`

参考仓库副本：`<本地参考仓库目录>/history_code`

助手采用独立 Python 工程、独立根目录 `.venv` 和终端入口。没有 GUI，没有注册到现有 FastAPI，也没有连接爬虫 Worker 或研究数据库。已经制作并验证可单独安装的 wheel 包，为后续总装保留稳定接口。

在助手目录双击 `启动终端.cmd` 使用真实模型，输入 `/exit` 退出；双击 `离线演示.cmd` 使用明确标记的假模型。命令与记忆操作详见该目录 README.md。

用户提供的密钥仅配置在助手本地 `.env`，没有写入源码、接口示例、报告或安装包。参考仓库里的旧凭据没有使用，旧记忆与个人提示词也没有导入。

## 已实现能力

- 以产业研究为背景，围绕口径、主体分类、证据缺口、来源同源与下一步行动给出建议。
- 多轮对话、指定会话续聊、人工事实记忆的增删改查。
- 聊天、事实记忆、自动摘要分别保存为 JSON 键值结构，按本次用户明确要求实施。
- 聊天轮号和记忆编号从1起；删除记忆不复用旧编号。
- 只保存成功的完整对话轮次，模型建议不自动写入事实库。
- 长对话支持滚动摘要；完整原始流水保留，摘要是未核实上下文。
- 对连接故障、408、429、5xx 有有限退避重试；其他错误提示修正。
- 同类文件读写、地址簿、模型契约与功能模块明确分层。

当前以完整回复方式输出，未实现逐字流式显示。助手没有搜索、抓取、外部发送、工具执行或自动修改研究数据的能力。

## JSON 存储结构

```text
data/
├── memory.json
│   └── {schema_version, next_id, entries: {"1": "人工确认事实", ...}}
└── sessions/<session_id>/
    ├── chat_history.json
    │   └── {schema_version, turns: {"1": {user, assistant, result, ...}, ...}}
    └── state.json
        └── {through_turn, summary}
```

会话历史按 session_id 隔离；人工事实在同一数据目录内共享。未来多个产业项目应分配各自的数据目录。采用 JSON 覆盖参考规范对人工库逐行纯文本的默认约定，这是用户在本次任务中的明确选择。
