## 环境与磁盘台账

环境为现有 Python 3.10 虚拟环境 myvenv，无系统 Python 替换，无 CUDA/PyTorch 安装。固定直接依赖见 requirement.txt，实际环境快照见 requirements.lock.txt。

安装前 C 盘可用 117431595008 字节；安装、模型缓存和原始下载后约 116418314240 字节，减少约 1.01GB（含安装包、缓存及虚拟环境；不全是研究数据）。系统盘可用仍约 108GiB。本轮单个向量模型仅约 24MB，原始研究数据远低于 1GB；大规模后续原始采集仍按既有规则改用非系统盘并登记。

默认源的大文件下载停滞，已改用可访问镜像完成 XGBoost 和 SciPy 下载；没有关闭 TLS 验证。部分 Hugging Face 直连路径报 TLS EOF，通过环境代理获取公开 tokenizer；准备命令已保留明确的网络失败提示与有限回退。

本轮未删除目录、未改 remote、未推送。环境安装已在对话提前报备。原有 CoMind 规范目录只读。
