# 抓取策略表（判定层 ↔ 工具箱 的合同）

> 本文件是**唯一契约**：判定层按它产出 `verdict`，工具箱按它选工具。
> 两边改之前先改这里，否则会各写各的。

---

## 一、为什么需要这张表

原来 `web_check.py` 判完就丢，抓取层仍然"一套代码打天下"。现在拆成两步：

```
① 探测判定（probe.py）  →  每个 URL 一份 profile（落盘，可复用）
② 选工具（route.py）    →  按 profile 的 verdict 决定这次用哪个抓取档
```

好处：97% 的站停在 0 依赖档，只有少数才升级；判定结果存盘后不必每次重判。

---

## 二、verdict 枚举（8 个，不多不少）

| verdict | 含义 | 判定依据（证据字段） |
|---|---|---|
| `robots_disallow` | robots 明确禁止 | `robots.allowed is False` |
| `pdf` | 非网页，直接当文件存 | `content_type == "pdf"` |
| `static` | 静态 HTML，正文够用 | 200 且 `text_chars >= 300` 且无动态特征 |
| `thin_static` | 静态但正文太少 | 200 且 `text_chars < 300` |
| `dynamic` | 需 JS 渲染才出正文 | 返回 setCookie 脚本 / 正文空骨架 / noscript 提示 |
| `blocked` | 403 / 503 / 风控拦截 | 状态码或 CF/风控特征头 |
| `login_wall` | 登录墙 | 跳转到 login 或页面含登录表单 |
| `error` | 探测本身失败 | 超时 / 5xx / 解析失败 |

**优先级（从高到低，前面的命中就不再看后面）**：

```
error > robots_disallow > blocked > login_wall > pdf > dynamic > thin_static > static
```

> 注意：`error` 最高，因为探测失败时其余判断都不可信。

## 三、profile 结构（probe.py 产出，route.py 消费）

```python
{
  "url":          str,            # 原始 URL
  "site":         str,            # 主机名，如 "tjj.guiyang.gov.cn"
  "checked_at":   str,            # ISO8601，本地时间
  "http_status":  int | None,
  "final_url":    str | None,     # 跟随重定向后的地址
  "robots": {
      "found":       bool,        # robots.txt 是否存在
      "allowed":     bool | None, # None = 无法判定（网络错误等）
      "crawl_delay": float | None,
      "error":       str | None,
  },
  "content_type": "html" | "pdf" | "other" | None,
  "encoding":     str | None,
  "bytes":        int | None,
  "text_chars":   int | None,     # 去标签后中文字符数
  "verdict":      str,            # 第二节的 8 个枚举之一
  "reason":       str,            # 一句话中文结论（给人和日志看）
  "signals": {                    # 判定证据，键固定，没命中给 None/False
      "spa_mount":     str | None,
      "noscript_hint": bool,
      "login_form":    bool,
      "cookie_script": bool,
      "cf_header":     bool,
      "script_ratio":  float | None,
  },
  "error":        str | None,     # verdict == "error" 时的原因
}
```

🔴 **`signals` 的键必须固定**（哪怕值是 None），否则下游没法稳定读取。

## 四、工具档位（route.py 的产出）

| tool | 依赖 | 何时选 | 现在能不能用 |
|---|---|:-:|:-:|
| `skip` | 0 | verdict 为 `robots_disallow` / `login_wall` | ✅ |
| `pdf` | 0 | `pdf` | ✅ |
| `static` | 0 | `static` | ✅ |
| `static_retry` | 0 | `thin_static`（换编码/去掉多余路径再试一次） | ✅ |
| `impersonate` | curl_cffi | `blocked` | ❌ 未装，返回不可用 |
| `browser` | Patchright | `dynamic`；或 `blocked` 且 `impersonate` 失败 | ❌ 未装，返回不可用 |
| `skip_retry` | 0 | `error`（留给上层决定重试） | ✅ |

> ✅ 档位**现在零依赖就能跑**；❌ 档位只留接口，`available: false`，等实测确需再装。

## 六、编码约束（必须遵守，否则不进工具层）

1. **零 `print`**：所有显示交给 `main.py`；需要进度用回调。
2. **HTTP 只走 `net.fetch`**；**落盘只走 `io_utils`**；**路径只从 `Path_Store` 取**。
3. 中英混排的中文注释 + 模块 docstring 必须包含：函数结构树 / 调用关系总览 / 数据流单链路 / 对外返回契约（照 `page.py`、`web_check.py` 的写法）。
4. 导入使用现有 fallback 模式：

```python
try:
    from Path_Store import Path_Store as ps
    from webcrawl import html_utils, io_utils, net, web_check
except ImportError:
    sys.path.insert(0, str(Path(__file__).resolve().parents[1]))
    from Path_Store import Path_Store as ps
    from webcrawl import html_utils, io_utils, net, web_check
```

5. 纯逻辑部分（判定规则）必须能**离线单测**：判定函数只吃字符串/dict，不碰网络。
