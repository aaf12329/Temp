# 建模研究来源示例

这里保存桌面“数学建模测试集”的公开网址与口径配置，便于版本管理和复现。它是待采集的来源集，**不是已经通过检查的数值训练集**；网页年份连续不等于已抽取观测连续。

## 来源与方向

年度公报由国家统计局发布，在教育部经费监管事务中心主办的[中国教育经济信息网](https://www.cee.edu.cn/n171/n58287/n58301/index.html)转载。目录中保留来源与逐页核对状态。2000、2008、2017、2025年曾浏览抽查；其余链接只从目录发现，没有逐页验证正文和口径。

优先尝试全国粮食年度总产量，棉花、油料产量为备选。使用独立配置，不将夏粮/秋粮/分品种产量、种植面积、单产、工业植物油产量、政策目标等混成一个序列。转载与原始公报属于同一证据，不能重复计数。

## 文件和使用

- `01_公报网址_2000-2025.txt`：26个年度入口，建议先用。
- `02_公报网址_1978-2025.txt`：48个入口，包含前一份；较早网页的转载日期不一定是原始公开日期。
- `来源目录.csv/json`：来源说明和核对状态。
- `配置_全国粮食.json`、`配置_全国棉花.json`、`配置_全国油料.json`：基于现有CLI配置，只明确词表、全国地域别名和本轮单口径限制。没有降低真实数据门槛、改变GAN原JSON或5倍生成规则。

在项目根目录运行（命令会正式采集并处理数据，最终LLM是否调用取决于配置）：

```powershell
.\.venv\Scripts\python.exe -m app.pipeline_cli --config examples/research_sources/配置_全国粮食.json --urls-file examples/research_sources/01_公报网址_2000-2025.txt --query "研究全国粮食年度总产量的发展趋势，仅使用全国全年粮食总产量，不混入分季节、分品种产量"
```

CLI使用根统一解释器，结果写入output/cli并覆盖登记的旧产物；重要结果应另存。网页仍读取config/cli.json，不会自动加载示例配置。所有采集继续遵守Robots、人工站点策略和公网地址限制；若被拒绝，保留原因并跳过。

26年/48年材料主要用于调查XGBoost是否够用，时间划分后不能满足64条真实训练行的WGAN门槛。仅发布在现代年鉴中的历史修订表，也不能把历史年份当成真实公开日期来绕过时点闸门。

## 当前真实验证

2026-10-22已用26网址和粮食配置调用正式CLI，关闭最终LLM，没有降低门槛。26个网址全部因非公网DNS结果被网络闸门阻断；本机www.cee.edu.cn解析为198.18.0.22。实际取得正文0份，未启动XGBoost或WGAN，不能据此断言来源数据量不足，也不能宣称真实预测成功。
